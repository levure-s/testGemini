# 血液型ファッション診断アプリ

ユーザーが自分の血液型を選択すると、その血液型に応じた服装提案を表示する Flutter アプリです。

## 機能

- 血液型選択（A 型、B 型、O 型、AB 型）
- 血液型に応じたファッション提案の表示
- モダンで使いやすい UI
- リセット機能

## プロジェクト構造

```
lib/
├── main.dart              # アプリのエントリーポイント
├── models/
│   └── outfit_model.dart  # 血液型別服装提案ロジック
└── screens/
    └── home_screen.dart   # メイン画面（血液型選択・提案表示）
```

## 血液型別ファッション提案

- **A 型**: きっちりシャツスタイル。清潔感を大事に！
- **B 型**: 自由でカジュアルなコーデ。派手色も OK！
- **O 型**: シンプル＆王道コーデ。誰からも好かれるよ！
- **AB 型**: 個性的でユニークな組み合わせに挑戦！

## セットアップと実行

1. Flutter 環境がセットアップされていることを確認
2. プロジェクトディレクトリで以下のコマンドを実行：

```bash
flutter pub get
flutter run
```

## 技術仕様

- **フレームワーク**: Flutter
- **言語**: Dart
- **UI**: Material Design 3
- **状態管理**: StatefulWidget
- **アーキテクチャ**: シンプルな MVVM パターン

## カスタマイズ

新しい血液型やファッション提案を追加する場合は、`lib/models/outfit_model.dart`ファイルの`_outfits`マップを編集してください。
